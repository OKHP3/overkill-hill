# MurderBird production has a dedicated home

New creative work belongs in [MurderBird: Uncaged](https://github.com/OKHP3/murderbird-uncaged).
The music and video source trees were transferred there with their original
relative paths and verified file hashes on September 26, 2026.

The `images/` sources retained here support existing website asset builders.
They are compatibility snapshots. See the
[repository boundary](../../../docs/murderbird-repository-boundary.md) for
the transfer record, private archive boundary, and rollback instructions.
